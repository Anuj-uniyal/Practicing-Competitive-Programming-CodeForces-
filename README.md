## 🧠 Problem-Solving Workflow

```text
Understand the Problem
        ↓
Analyze Constraints
        ↓
Try Small Examples
        ↓
Find Observations
        ↓
Think of Brute Force
        ↓
Find the Bottleneck
        ↓
Optimize
        ↓
Prove the Idea
        ↓
Implement
        ↓
Test Edge Cases
        ↓
Analyze Complexity
```

### Before reading an editorial

- ⏳ Give the problem a genuine attempt.
- 📝 Write down observations, even if they seem incomplete.
- 🧪 Test the idea on small and edge cases.
- 🔍 Identify exactly where the current approach fails.
- 📖 If you read the editorial, explain the idea again in your own words.
